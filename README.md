# 室内植物 栽培記録（zukan）

「観葉植物 栽培台帳」をもとにした、室内植物13種の栽培リファレンスツール。

- HTML/CSS/JSのみの静的ツール。インストール不要、`index.html` をブラウザで開くだけで使えます（サーバー不要）。
- データはすべて `data.js` に入っている。書き込み・保存機能はなく、閲覧専用（栽培記録を読む・検索するためのツール）。
- 書体は游ゴシック、配色は元の栽培台帳のカラーパレット（深緑・真鍮色・生成り紙の色）を踏襲。

## できること

- **ホーム**：今月やるべきことを、13鉢分まとめて一覧表示（毎回パソコンの日付から自動で「今月」を判定）
- **植物図鑑**：13種それぞれの性質・水やり/肥料の目安・巨大化のコツ・生態の解説・月別管理表・よくある悩みQ&A。名前や学名で検索可能
- **月別ガイド**：4月から3月まで、その月にやることだけを読み下せる形にまとめたもの
- **トラブル対策**：葉が黄色い・茶色いなどの症状から原因と対処を探す。症状名で検索可能
- **基本ガイド**：光・水・肥料・植え替え・支柱・剪定など、管理の考え方の土台になる8章
- **道具・チェックリスト**：資材の一覧と、毎月15分でできる巡回チェック

## 内容を増やす・書き換える

`data.js` の先頭に、植物・月別ガイド・トラブル項目を追加するときの書式をコメントで書いてある。基本的にはそこだけ編集すればよく、`index.html` / `style.css` / `app.js` を触る必要はない。

新しいセッションでClaude Codeに頼む場合は「zukanに◯◯を追加して」と伝えれば、`data.js` の該当箇所を見て追記できる。

## 動作確認の方法

Node.jsなどのインストールは不要。`index.html` をダブルクリックしてブラウザで開くだけで動作する。

ローカルでサーバー経由で確認する場合：

```
powershell -File serve.ps1
```

`http://localhost:4173/` で表示される。

## 更新の流れ

`data.js` / `app.js` / `style.css` を編集して保存すると、開いているブラウザをリロードするだけで反映される（ビルド作業は不要）。GitHub Pagesで公開している場合は、編集 → コミット → push すると自動で反映される。
